Current Truth

rn-charts is a Skia-based React Native chart library with composable labels, renderers, selection, and popups.

This package exports AreaChart, BarChart, HeatMap, PieChart, and RadarChart. The implementation is mostly TypeScript and React Native UI on top of @shopify/react-native-skia, with a small required native popup helper for full-screen outside-press reporting.

Install & Run

Package dependencies

The package depends on @bashem/rn-popup as a normal dependency. App users also need the chart peer stack: React, React Native, Skia, Gesture Handler, Reanimated, and Worklets.

Architecture

Each chart file owns public props and mixes Skia canvas with React Native overlays.

Hooks calculate dimensions, paths, selected data, label positions, and touch handling.

Shared helpers

Common padding and label components keep axis behavior consistent across chart types.

The shared popup bridge uses @bashem/rn-popup for outside-touch notification.

Render layers

Skia draws fast primitives such as paths, rects, gradients, polygons, and circles. React Native views render labels, center content, selected overlays, and popup children.

Common Props

Concept Where Meaning
CommonStyle Most chart style objects Supports padding, background color, and RTL-aware left/right/start/end padding.
minValue / maxValue Area, Bar, HeatMap, Radar Override computed value ranges when you need stable chart scale across renders.
xLabelView / yLabelView Area, Bar, HeatMap Render React Native labels around Skia canvas content.
Skia render callbacks Bar, HeatMap, Radar labels Inject custom Skia elements for cells, bars, selected states, or labels.
popupStyle Area, Bar, HeatMap, Pie Defines fixed popup dimensions and a React renderer for selected data.

AreaChart

Data shape

type AreaData = {
  values: number[];
  label?: string;
  color?: string;
};

Each item is a series. Touching a column selects values from every series at that x-index, so the popup can render multiple rows.

Main props

data, yLabels, xLabels, minValue, maxValue, xLabelView, yLabelView, popupStyle, and style.

Style supports fixed width and height, point radius, point lightening, and vertical/horizontal label styling. 

<AreaChart
  data={areaData}
  minValue={0}
  maxValue={80}
  xLabels={["Jan", "Feb", "Mar"]}
  yLabels={[1, 0.5, 0]}
  popupStyle={{
    width: 132,
    height: 54,
    renderPopup: ({ rowIndex, value }) => popupText(areaData[rowIndex]?.label ?? "Series", value),
  }}
  style={{ width: chartWidth, height: 230, pointRadius: 4 }}
/>

BarChart

Data shape

type StackValue = {
  value: number;
  label: string;
  id?: string;
};

type BarData = {
  values: StackValue[];
  label?: string;
};

Each bar can contain multiple stack values. Colors are resolved by stack id or label.

Customization

Use colors for solid or gradient fills, barSkiaView to fully replace bar drawing, onSelectBarView for React Native overlays, and onSelectBarSkiaView for Skia overlays.

Horizontal scroll Stacked values Selection overlays 
<BarChart
  data={barData}
  colors={{
    equity: ["#2563EB", "#38BDF8"],
    cash: ["#F97316", "#FACC15"],
  }}
  yLabels={[1, 0.75, 0.5, 0.25, 0]}
  popupStyle={{
    width: 124,
    height: 54,
    renderPopup: (value) => popupText(value.label, value.value),
  }}
  style={{ width: chartWidth, height: 220, barWidth: 32, barSpacing: 18 }}
/>

HeatMap

Data shape

type HeatMapDataGroup = {
  cols: number;
  startingRow: number;
  endingRow: number;
  data?: Record<number, Record<number, number>>;
};

Groups let you model streaks or blocks of cells. startingRow and endingRow describe how a group flows through rows.

Customization

Use cellSize, cellGap, cellMinColor, and cellMaxColor for the built-in color ramp. Use cellSkiaView to replace cell drawing.

onSelectView and onSelectSkiaView render selected-cell overlays. 

<HeatMap
  rows={7}
  data={heatMapData}
  minValue={0}
  maxValue={24}
  xLabelView={(index, width) => <Text style={{ width }}>W{index + 1}</Text>}
  yLabelView={(index) => axisLabel(dayLabels[index] ?? "")}
  popupStyle={{
    width: 112,
    height: 54,
    renderPopup: (datum) => popupText(`R${datum.rowIndex + 1} C${datum.colIndex + 1}`, datum.value),
  }}
  style={{ cellSize: 24, cellGap: 5 }}
/>

PieChart

Data shape

type PieSlice = {
  value: number;
  color?: string;
  label?: string;
  radius?: number;
};

Slices are normalized by total value. The optional slice radius controls rounded corner drawing.

Center content

Use centerView for React Native content inside the donut, or centerSkiaView for Skia content. onSliceTouch reports selected slice data. 

<PieChart
  slices={pieSlices}
  onSliceTouch={(slice) => setSelectedSlice(slice)}
  centerView={<Text>100%</Text>}
  popupStyle={{
    width: 116,
    height: 54,
    renderPopup: (slice) => popupText(slice.label ?? "Slice", `${slice.value}%`),
  }}
  style={{ radius: 128, innerRadius: 62, interSliceGap: 0.02, padding: 10 }}
/>

RadarChart

Data shape

type RadarDatum = {
  values: number[];
  backgroundColor?: string;
  strokeColor?: string;
  strokeWidth?: number;
};

Each datum draws a polygon. Every polygon should have the same number of values as the label count.

Main props

Use labels for text labels, labelViews for custom React label nodes, levels for grid rings, and minValue/maxValue for scale.

RadarChart does not currently use popup integration.

<RadarChart
  data={radarData}
  labels={["Growth", "Risk", "Income", "Fees", "Quality"]}
  levels={5}
  minValue={0}
  maxValue={100}
  style={{ size: 320, strokeWidth: 1, centerDotRadius: 3 }}
/>

Labels & Renderers

React Native labels

xLabelView and yLabelView return React Native elements. The shared label containers measure those views and reserve axis space. 

yLabelView={(percentage, min, max) =>
  axisLabel(String(Math.round(min + (max - min) * percentage)))
}

Skia render callbacks

Some charts expose Skia callbacks for custom primitives. BarChart supports custom bars and selected bars. HeatMap supports custom cells, selected cells, and Skia labels. 

cellSkiaView={(rect, datum) => (
  <Rect rect={rect} color={datum.value > 10 ? "#15803D" : "#DCFCE7"} />
)}
Label sizing is dynamic unless you provide explicit axis label dimensions such as verticalLabelStyle.width or horizontalLabelStyle.height.

Popup Behavior

Contract

The shared src/skia/Popup.tsx bridge renders React popup children through @bashem/rn-popup. It sets native outsideTouchBehavior to pass-through, so native reports outside touches and lets that same touch reach the underlying view.

Caller-owned state

The popup does not decide whether selection should be cleared. The chart that passes onTouchOutside owns that behavior. Current chart integrations clear selected popup state in their callback.

Requirement Reason
popupStyle.width and popupStyle.height The native helper uses the first child as the popup hit area, so the bridge needs fixed bounds.
renderPopup(data) Transforms selected chart data into React Native popup content.
viewOffset Measured chart screen position lets root-host popup content appear at the intended chart coordinate.

Example App

The example app uses Expo Router and renders all chart examples in one scroll view. Each chart is split into its own component under example/components.

Route

example/app/index.tsx computes a responsive chart width and stacks every example.

Examples

AreaChartExample, BarChartExample, HeatMapExample, PieChartExample, and RadarChartExample.

Shared UI

example/components/shared.tsx provides section wrappers, axis labels, and popup text.

The example screen also includes top and bottom touch target buttons with counters. Open a chart popup, press one of those buttons, and compare whether the counter changes to confirm whether the outside touch reached the underlying React Native view.

Fast Feedback

Editing chart JS or TS

Keep Metro running and use Fast Refresh. This covers most changes in rn-charts/src and rn-charts/example.

Editing popup native code

Rebuild and reinstall the example app. Native Kotlin changes in rn-popup do not hot reload into an installed development build.

Editing generated package output

Source is under src. Build output under lib is generated by bob build.

Debugging

Popup does not appear

Confirm popupStyle.width, popupStyle.height, and popupStyle.renderPopup are provided. The shared popup returns null without dimensions.

Native view not found

Rebuild the development app and confirm Gradle includes :bashem_rn-popup. 

example/android/gradlew -p example/android projects

Selection coordinate feels wrong

Check chart padding, vertical label width, horizontal label height, and whether the selected data is in chart-space or root-screen-space.

Lint noise

The current package has broad existing Prettier/style issues. Use npm run typecheck as the narrowest reliable check when you are not intentionally formatting the project.
